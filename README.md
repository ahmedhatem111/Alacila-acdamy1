# أهلية أكاديمي — وضع الضيف المحلي

الموقع يعمل على **GitHub Pages** دون اتصال بقاعدة بيانات. شاشة الدخول تقبل أي اسم وكلمة مرور غير فارغين وتفتح جلسة ضيف محلية؛ لا يتم التحقق من الهوية أو حفظ كلمة المرور. بيانات الجلسة تبقى على هذا الجهاز فقط، وتُحذف عند تسجيل الخروج. هذا الوضع مناسب للتجربة وليس لحسابات الطلاب أو البيانات الخاصة.

## النشر على GitHub Pages
ارفع محتويات هذا المجلد إلى مستودع GitHub على فرع `main`. من **Settings → Pages → Build and deployment** اختر **GitHub Actions** كمصدر. سير العمل في `.github/workflows/pages.yml` ينشر الموقع عند كل تحديث للفرع؛ لا يحتاج إلى أسرار Supabase.

ملف `supabase.sql` محفوظ كمرجع فقط ولا يشغّله الموقع. تعطيل الاتصال هنا لا يحذف مشروع Supabase أو البيانات الموجودة فيه؛ احذف المشروع يدويًا من لوحة Supabase فقط إذا كنت متأكدًا أنك تريد محوها.

## تثبيت الموقع كتطبيق على التلفون
- أندرويد (Chrome): هيظهر زر «ثبّت التطبيق» في صفحة الترحيب، أو من قائمة المتصفح ← تثبيت التطبيق.
- آيفون (Safari): زر المشاركة ← إضافة إلى الشاشة الرئيسية.

## لازم تعرف
- الجداول والمواعيد والكورسات المحفوظة تعمل محليًا في المتصفح، ولا تتزامن بين الأجهزة أو المستخدمين.
- وضع الضيف ليس نظام تسجيل آمنًا: أي شخص يستخدم المتصفح نفسه يستطيع إنشاء جلسة محلية جديدة.
- **ملفات الـ PDF والصفحات علنية.** GitHub Pages ما بيقدرش يقفل ملفات. قفل الصفحات حسب السنة/التخصص بيمنع الطالب من الواجهة، لكن اللي يعرف رابط ملف PDF يقدر يفتحه. لو المحتوى لازم يفضل خاص فعلًا، محتاج استضافة بسيرفر (نسخة Flask اللي بعتهالك قبل كده) أو Supabase Storage.
- الشهادة بتتحسب في المتصفح وبتتطبع، مش وثيقة موثّقة.
